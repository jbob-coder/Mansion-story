# Complete Initial World-Development Inventory

**Purpose:** an inspectable list of the world systems known at this planning stage. **This is not a claim of exhaustive possible world content**, and "canon/data defined" does **not** mean the system runs in gameplay.

**World premise:** a persistent RPG simulation from creation to a late medieval-fantasy era, with humans currently dominant within known inhabited society, one core ability per entity, divergent sub-abilities, genuine evil and moral conflict, and a historic archive of changes.

**Counts:** 68 registered systems in 9 disciplines; all require runtime implementation. Narrative worldbuilding and some data validation have been committed.

## Delivery roadmap
- **PHASE-001: Canon and reproducible references** — documentation and registry present. World layers, chronology, society, demographic estimates, evil and evidence-based validation.
- **PHASE-002: Event-sourced core state** — not implemented. Deterministic clock, actor state, resource transactions, terrain occupancy, save/replay.
- **PHASE-003: Autonomous inhabited ecology** — not implemented. Needs-based people and wildlife, food/resource loops and travel.
- **PHASE-004: Society and conflict** — not implemented. Markets, social learning, laws, elections, slavery resistance, warfare, diplomacy.
- **PHASE-005: Playable RPG experience** — not implemented. Player, simulation-backed character actions, meaningful UI, performance and release testing.

## Core technical dependencies
The simulation must have a single authoritative clock, entity ID registry, physical world state, resource journal, deterministic action resolution and append-only event history **before** believable autonomous building or organic governments are possible. Individual NPC planners and visual presentation consume this state; they must not invent inventories or instantaneous buildings.

## Completion policy
Every system moves through: proposed -> canon/data modeled -> engine implemented -> independently tested -> integrated -> released. A document or JSON object alone never passes the "engine implemented" gate. The current status field in `data/world/system_catalog.json` reports the truth.
